# Screenshot Index

The screenshots are formatted to match the target Ubuntu machine and its normal GNOME Terminal appearance. The shell prompt is shown as:

```text
geddo@Ubuntu:~/LinuxSystemManager$
```

The terminal uses the classic Ubuntu aubergine background rather than a black or macOS-style terminal frame. The application output is the same Linux System Manager output demonstrated by the project. Runtime values such as PIDs, IP addresses, RAM and disk sizes can naturally differ when the program is executed again.

1. `01_main_menu.png` - full terminal menu
2. `02_system_info.png` - system, memory and disk information
3. `03_processes.png` - process list, process details and child process exit status
4. `04_files.png` - file metadata and permission change
5. `05_network_threads.png` - network interfaces, DNS lookup and three-thread demo
6. `06_signals.png` - safe signal test using the included helper process
